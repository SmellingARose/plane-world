Rigid body: forces in, motion out

The whole craft is one rigid body. Each substep sums every force F and torque T from all parts, then updates velocity and spin. The step is tiny (h = 1 ms), which keeps stiff things like tyres stable.

v ← v + (F/m)·h    x ← x + v·h    L ← L + T·h    ω = I⁻¹L Symplectic (semi-implicit) Euler: update velocity first, then use the new velocity for position. Angular momentum L is integrated, not ω, so spinning objects keep their energy.
Derivation
  1. Newton: m·dv/dt = F. Over a short step h, dv ≈ (F/m)·h.
  2. Plain (explicit) Euler uses the old v for position and slowly gains energy in oscillations. Using the new v (symplectic Euler) keeps energy bounded, which is why orbits and springs don't blow up.
  3. Rotation: dL/dt = T (torques change angular momentum). The angular velocity follows from ω = I⁻¹L, with I the inertia tensor rotated into world space.
function step(b, F, T, h) {
  b.v = add(b.v, scale(F, h / b.m));      // velocity first
  b.x = add(b.x, scale(b.v, h));          // then position with the NEW velocity
  b.L = add(b.L, scale(T, h));
  b.w = mul(b.Iinv_world, b.L);           // ω from angular momentum
  b.q = integrateQuat(b.q, b.w, h);       // rotate orientation by ω·h
}

Air properties

Air: density, viscosity, wind

q = ½ρV²Dynamic pressure. Every aerodynamic force below is q × area × a coefficient.
μ = 1.458·10⁻⁶·T^1.5 / (T + 110.4)Sutherland's law: viscosity rises with temperature. Gives the Reynolds number Re = ρVc/μ.

Density ρ falls with altitude (standard atmosphere), so the same speed gives less lift high up. Wind grows with height like a log profile, plus frozen turbulence that the craft flies through.

Wings: strip theory

Each wing is cut into narrow spanwise strips. Each strip measures the air it actually feels (craft speed, its own rotation, wind and prop wash), finds its angle of attack α, and looks up lift and drag coefficients.

C_L = a·(α − α₀)
a = 2πA / (2 + √(A²β²/κ² + 4))Lift slope a shrinks for short wings (aspect ratio A) because tip vortices bleed lift. β = √(1−M²) adds compressibility.
C_D = C_D0 + C_L²/(πAe) + …Profile drag plus induced drag. Induced drag is the price of lift, and it falls as wings get longer.

Lift curve

Slope a = /rad

Linear until the stall angle, then it blends over 12° toward a flat plate (C_L = 2 sin α cos α). Short wings have gentler slopes.

Derivation of the lift slope
  1. Thin-airfoil theory (infinitely long wing): C_L = 2π·α. A 2D section gains 2π per radian.
  2. A finite wing sheds tip vortices that push air down (downwash). The wing sees a smaller effective angle: α_eff = α − C_L/(πA) (lifting-line, elliptic loading).
  3. Substitute: C_L = 2π(α − C_L/(πA)) → C_L = 2π·α / (1 + 2/A). This is the classic Prandtl result.
  4. Helmbold's formula fixes it for short and swept wings, and the β term adds compressibility (Prandtl–Glauert). That's the a used here.
function wingStrip(alpha, V, rho, S, A, cl0, cd0, e = 0.8) {
  const a = 2*Math.PI*A / (2 + Math.sqrt(A*A + 4));        // lift slope (M≈0)
  const stall = 15 * Math.PI/180;
  let cl = cl0 + a*alpha;                                   // attached flow
  if (Math.abs(alpha) > stall) {                            // blend toward flat plate
    const t = Math.min(1, (Math.abs(alpha)-stall) / (12*Math.PI/180));
    cl = (1-t)*(cl0 + a*stall*Math.sign(alpha)) + t*2*Math.sin(alpha)*Math.cos(alpha);
  }
  const cd = cd0 + cl*cl/(Math.PI*A*e);                     // + induced drag
  const q = 0.5*rho*V*V;
  return { lift: q*S*cl, drag: q*S*cd };                    // ⟂ and ∥ to the local flow
}

Bodies: drag and Newtonian panels

D = ½ρV²·C_D·S_projPrimitive parts: a drag coefficient times the area they show to the flow.
C_p = C_p,max·cos²θCAD meshes: every triangle facing the wind gets pressure from its angle θ to the flow (modified Newtonian). Hidden triangles are shadowed.

Newton's own idea: air is a stream of particles that hit a surface and lose their normal momentum. It's exact at hypersonic speed and only roughly right at low speed, which is why the docs flag it as the least accurate fast model.

Derivation of the Newtonian pressure
  1. Mass flow hitting a panel of area A tilted θ from the flow: ṁ = ρV·A·cos θ.
  2. Each particle loses its normal velocity V·cos θ. Force = ṁ·V cos θ = ρV²A cos²θ.
  3. Divide by qA: C_p = 2cos²θ. The "modified" version swaps 2 for C_p,max (≈1 + M²/4 at low speed).
for (const tri of mesh) {
  const c = -dot(tri.normal, flowDir);                      // cos θ (facing the flow?)
  if (c > 0 && !tri.shadowed) force = add(force, scale(tri.normal, -cpMax*c*c*q*tri.area));
}

Turning power into thrust

Propellers: momentum theory

The propeller is a disk that speeds up the air passing through it. Push air backward and the air pushes you forward. Given engine power P, the disk settles where the power going into the air matches the power available.

T·(V + v_i) = η·PPower into the air = thrust × air speed at the disk. η ≈ 0.75 for losses.
v_i = −V/2 + √(V²/4 + T/(2ρA))Induced velocity at the disk. Solved together with the line on the left (Newton iteration).

Thrust vs airspeed (same engine power)

Static thrust =

Thrust is highest at zero speed and falls as you fly faster, since the same power pushes less force at higher speed. A bigger disk gives more static thrust for the same power.

Derivation (actuator disk)
  1. Air enters at V, passes the disk at V + v_i, leaves far behind at V + 2v_i (Bernoulli on each side of the disk gives the factor 2).
  2. Mass flow through the disk: ṁ = ρA(V + v_i). Thrust = ṁ × change in speed = ρA(V + v_i)·2v_i.
  3. Solve that quadratic for v_i: v_i = −V/2 + √(V²/4 + T/(2ρA)).
  4. Ideal power = T·(V + v_i). Real power is larger by 1/η.
function propThrust(P, D, rho, V, eta = 0.75) {
  const A = Math.PI*D*D/4;
  let T = Math.cbrt(2*rho*A*(eta*P)**2);                    // static guess
  for (let k = 0; k < 8; k++) {                             // Newton on f(T) = T(V+vi) − ηP
    const vi = -V/2 + Math.sqrt(V*V/4 + T/(2*rho*A));
    const f = T*(V+vi) - eta*P;
    const dvi = 1/(4*rho*A*Math.sqrt(V*V/4 + T/(2*rho*A)));
    T -= f / (V + vi + T*dvi);
  }
  return T;
}

Parts feeling each other's air

Slipstream: the wake behind a rotor

The air a propeller accelerates keeps going. Anything behind it, like a tail, a second propeller or a duct, feels that extra flow. The wake speeds up, narrows, swirls in the direction the prop spins, and slowly mixes out.

Δv(s) = v_i·(1 + s/√(s² + R²))s = distance downstream of the disk. Upstream (s→−∞): 0. At the disk: v_i. Far downstream: 2v_i. That's the same factor 2 as in momentum theory.

Axial speed-up along the wake

Ducted rotors don't contract their wake, and their exit speed equals the disk speed. That's why a duct gives more thrust for the same power: it acts like a bigger open rotor.

R_s = R·√((V + v_i)/(V + Δv))Wake contraction from continuity: faster air needs a narrower tube.
T_IGE/T_OGE = 1/(1 − (R/4z)²)Rotor ground effect (Cheeseman–Bennett): near the ground, the same power gives more thrust.
function wakeSpeedUp(p, disk) {                            // induced velocity at point p
  const d = sub(p, disk.center), s = dot(d, disk.axis);     // distance along the wake
  const dv = disk.vi * (1 + s / Math.hypot(s, disk.R));     // vortex-cylinder profile
  const r  = len(sub(d, scale(disk.axis, s)));              // distance from the wake axis
  const Rs = disk.R * Math.sqrt((disk.V+disk.vi)/(disk.V+dv));
  const inside = r < Rs ? 1 : 0;                            // (code uses a smooth edge)
  return scale(disk.axis, dv * inside * Math.exp(-Math.max(s,0)/(14*disk.R)));
}

The extra effects

T_gyro = −ω_body × (I_r·Ω)Gyroscopic rotors. A spinning prop resists being tilted. Pitch the nose and the craft yaws instead.
ε ≈ 2C_L/(πA)Wing downwash. The main wing bends the air down, so the tail sees a smaller angle of attack. Modelled with horseshoe vortices and Biot–Savart.
N ≈ T·k_N·sin α_pP-factor. At a high angle, the descending blade takes a bigger bite: a sideways force plus a yawing moment.
wake × attenuation(body)Blockage. A body sitting in a wake shadows what's behind it. CAD wash: each mesh triangle feels the prop wash too.
